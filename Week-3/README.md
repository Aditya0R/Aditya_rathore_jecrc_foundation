# Country Segmentation using Unsupervised Learning

## Objective

The objective of this project is to classify countries based on socio-economic and health indicators and identify countries that require humanitarian aid.

## Dataset

- 167 Countries
- 9 Numerical Features

## Techniques Used

- Exploratory Data Analysis
- StandardScaler
- K-Means Clustering
- Elbow Method
- Silhouette Score
- PCA

## Key Findings

Countries were segmented into three clusters:

1. Developed Countries
2. Developing Countries
3. Underdeveloped Countries

The underdeveloped cluster was identified as the highest priority group for NGO aid allocation.
